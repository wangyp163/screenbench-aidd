# Phase 0 · 切分方式泄漏实测（MoleculeNet HIV · TDC 同源）

- 数据：28607 分子（活性 3.2%），唯一骨架 13785 个
- 特征：Morgan ECFP4 (2048 bit)；模型：RandomForest(200 trees)；3 个种子
- 测试集均 ~20%：random = 随机分层；scaffold = 按骨架分组（同骨架不跨侧）

| 切分 | ROC-AUC (mean ± std) |
|---|---|
| random   | 0.8478 ± 0.0138 |
| scaffold | 0.8264 ± 0.0183 |
| **泄漏虚高** | **+0.0214（相对 2.6%）** |

## 一句话结论
随机切分比骨架切分虚高 **2.6%**——高出的部分不是模型学到了通用规律，
而是「测试分子和训练分子同骨架」的记忆分。真实筛选场景遇到的是新骨架，所以药物域统一评测
（TDC 等）默认 scaffold split。这就是「冻结评测集 + 防泄漏切分」存在的意义。
